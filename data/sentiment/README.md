# Sentiment input data contracts

All dates use `YYYY-MM-DD`; monetary units only need to be consistent inside a ratio.

- `option_volume.csv`: all 50ETF contracts, one row per contract/day, C/P volume.
- `float_market_cap.csv`: total A-share free-float market capitalisation by day.
- `ivix.csv`: historical daily VIX30 generated by `ivix_index_pipeline.py`.
- `new_high.csv`: five-year-high count and eligible A-share count. A long
  `stock_daily.csv` (`date,symbol,close`) may be supplied instead and is recomputed.
- `basis.csv`: IF-main annualised basis; alternatively include
  `futures_close,spot_close,expiry`.
- `stock_bond_turnover.csv`: secondary-market stock and bond turnover by day.

`benchmark.csv` and `margin_balance.csv` are cached automatically from AKShare.
Pre-computed PCR/percentile columns are accepted, but formal runs should preserve
source lineage and must not mix synthetic records.

## Real-data updater

Run from the project root. With no positional command it runs all components;
each component is resumable and preserves its raw source/unit columns.

```powershell
.\.venv-qlib\Scripts\python.exe sentiment_akshare_downloader.py `
  --data-dir data\sentiment --start-date 2019-01-01 --workers 6
```

Individual tasks are `daily`, `basis`, `new-high`, `ivix`, and `audit`.
`data_quality_report.csv/json` records date coverage, duplicates, core nulls and
source notes. The early SSE stock-summary archive gap is filled from AKShare's
per-stock amount/turnover fields and explicitly marked `is_estimated=True`;
official SSE+SZSE observations always take precedence. Bond turnover is never
estimated. The bond scope is the SSE+SZSE exchange secondary market and excludes
the interbank bond market.
