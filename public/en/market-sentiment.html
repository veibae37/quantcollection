QRS timing overlay

QRS: index support and resistance

Loading the latest QRS observations

QRS is an index exposure overlay, not a stock-selection model or a source of index-enhancement alpha. It can adjust the risk budget of an existing portfolio. A reading above +0.15 switches to long exposure; below −0.15 switches to cash. Between the thresholds, the previous state is retained.

Method

How the score is built

Each component contributes −1, 0 or +1, combined using fixed weights. Calculations use retrieved market observations; missing data is never replaced with simulated values.
